## 7. User Stories

Voor het project hebben we de belangrijkste functies omgezet naar user stories.

- Als gebruiker wil ik alle recepten kunnen bekijken, zodat ik kan kiezen wat ik wil koken.
- Als gebruiker wil ik kunnen zoeken naar een recept, zodat ik snel een geschikt recept kan vinden.
- Als gebruiker wil ik recepten kunnen filteren op categorie, zodat ik makkelijker kan vinden wat bij mij past.
- Als gebruiker wil ik de ingrediënten en bereidingswijze van een recept kunnen bekijken, zodat ik het recept zelf kan maken.
- Als gebruiker wil ik een recept kunnen toevoegen, zodat ik nieuwe recepten kan opslaan.
- Als gebruiker wil ik een recept kunnen aanpassen, zodat verkeerde of verouderde informatie gewijzigd kan worden.
- Als gebruiker wil ik een recept kunnen verwijderen, zodat recepten die niet meer nodig zijn weggehaald kunnen worden.
- Als gebruiker wil ik de website goed kunnen gebruiken op mijn telefoon, zodat ik tijdens het koken makkelijk het recept kan bekijken.
- Als gebruiker wil ik kunnen inloggen, zodat ik toegang kan krijgen tot mijn account.

### Admin

- Als admin wil ik recepten kunnen beheren, zodat ik de inhoud van de website kan controleren.
- Als admin wil ik recepten kunnen aanpassen of verwijderen, zodat verkeerde recepten gecorrigeerd kunnen worden.
